# Nortor by faii — SMART FRIDGE ใหม่ (50 ขวด / 50 บาท)

สร้างโปรเจกต์ใหม่ **แยกจากโปรเจกต์เก่า** ไม่ต้องย้ายข้อมูลเดิม ไม่รัน migrateToV2

## สิ่งที่ทำได้
- สต๊อกเริ่มต้น 50 ขวด ราคา 50 บาทต่อขวด
- QR URL ประจำขวดไม่ซ้ำกัน และมีรหัส NBF-001 ถึง NBF-050
- สแกนหลายขวดรวมยอดได้ภายในเบราว์เซอร์เดียวกัน
- กรอกเฉพาะชื่อหรือชื่อเล่น (ไม่ต้องสมัครสมาชิกหรือกรอกเลขห้อง)
- กดซื้อแล้วขวดจะถูก CLAIMED และสร้างรายการ PENDING แม้ยังไม่จ่าย
- PromptPay แบบแสดงเลขรับโอน + แนบสลิป เจ้าของร้านตรวจเงินเอง
- Admin ดูรายการ ดูลิงก์สลิป อนุมัติหรือปฏิเสธ และพิมพ์ QR
- ป้องกันสแกนขวดซ้ำในรายการซื้อด้วย LockService

## ติดตั้ง
1. สร้าง Google Sheets **ใหม่** ชื่อ `Nortor by faii - NEW 50` ไม่ใช้ชีตเดิม
2. Extensions > Apps Script
3. วาง Code.gs ลงใน `Code.gs`; สร้างไฟล์ HTML ชื่อ `Index`, `Styles`, `Client` แล้วคัดลอกจากไฟล์ .html ที่ตรงกัน
4. กด Save แล้วเลือกฟังก์ชัน `setupNewStore` > Run เพียงครั้งเดียว > อนุญาตสิทธิ์
5. ตรวจว่ามีชีต Bottles และแถวสินค้า 50 ขวด NBF-001 ... NBF-050
6. Project Settings > Script Properties > Add script property:
   - `ADMIN_PASSWORD`: ตั้งรหัสผ่านยาวและไม่ซ้ำกับบริการอื่น
   - `PUBLIC_WEB_APP_URL`: **อย่าเพิ่งใส่** จนกว่าจะ Deploy และทดสอบลิงก์จริง
7. Deploy > New deployment > Web app > Execute as Me > Who has access Anyone (ถ้าบัญชีอนุญาต) > Deploy
8. คัดลอก Web app URL ที่ลงท้าย `/exec`, เปิดลิงก์โดยตรงบนมือถือ ทดสอบว่าเจอหน้า Nortor by faii
9. Project Settings > Script Properties > เพิ่ม `PUBLIC_WEB_APP_URL` ใส่ **URL /exec ที่เปิดได้จริงโดยไม่มี ?b=**
10. เปิดเว็บ Admin ใส่รหัสผ่าน ตั้งเลข PromptPay + ชื่อบัญชี แล้วกด **สร้าง QR 50 ขวด**
11. กดลิงก์ **เปิดลิงก์ทดสอบ** ที่ NBF-001 ก่อน: ต้องเปิดเว็บร้านและเพิ่มขวด NBF-001 ลงตะกร้า
12. เมื่อทดสอบผ่าน ให้พิมพ์ฉลากจากหน้า Admin แล้วติดลงบนขวดตรงหมายเลข

## คำเตือนสำคัญ
- URL ต้องเป็น https://script.google.com/macros/s/.../exec ซึ่งเปิดได้แล้วจริง; ไม่ใช่ googleusercontent.com และไม่ใช่ URL ของ Google Drive
- QR ในภาพพิมพ์จากบริการภายนอก api.qrserver.com; อย่าส่ง URL ที่มีข้อมูลลับ/ส่วนบุคคลไปผ่าน QR (URL นี้มีเฉพาะโทเคนขวด)
- รูปสลิปใน Drive เป็น private เจ้าของร้านสามารถเปิดดูได้เมื่อใช้บัญชีที่ถือสิทธิ์
- ปัจจุบันระบบ **ไม่ได้ตรวจสอบการชำระเงินอัตโนมัติ** และ QR ไม่ได้ตรวจการหยิบจริง
- ชื่อลูกค้าที่กรอกเองยังระบุตัวตนจริงไม่ได้
- การเก็บตะกร้าสำหรับสแกนหลายขวดใช้ localStorage ของเบราว์เซอร์เดียวกัน ในบางกรณี Safari / เบราว์เซอร์ภายในแอปอาจเปิด QR คนละ session; ต้องทดสอบจริงก่อนขาย
- หากผู้ใช้ปิดหน้าเว็บหลังสร้าง Order สามารถกลับมาที่เครื่องเดิมเพื่อส่งสลิปได้จากรายการที่บันทึกใน localStorage
- เมื่อทดสอบคำสั่งซื้อ ขวดจะถูกตั้งสถานะ CLAIMED และไม่สามารถนำ QR เดิมไปขายซ้ำได้ ระบบต้นแบบนี้ไม่มีปุ่มคืนสต๊อก; หากต้องการขายใหม่ต้องเพิ่มฟังก์ชันยกเลิกพร้อมตรวจสอบสต๊อกจริง
- อย่าแชร์ Google Sheets หรือโฟลเดอร์ Drive เป็นสาธารณะ; ทดสอบด้วยการซื้อสมมติและสลิปทดสอบก่อนใช้งานจริง


## เพิ่มรับชำระเงินสด (Cash Edition)
- ลูกค้าเลือกระหว่าง PromptPay + สลิป และเงินสด ก่อนกดยืนยันหยิบ
- เลือกเงินสด: รายการเป็น CASH_PENDING ระบบตัดสต๊อกเหมือนเดิม แต่ **ยังไม่ใช่ PAID**
- เจ้าของร้านต้องรับเงินสดจริง แล้วกดยืนยันใน Admin เท่านั้น จึงเปลี่ยนเป็น PAID
- ลูกค้าไม่สามารถเปลี่ยนสถานะตนเองเป็น PAID
- Orders เพิ่มคอลัมน์ payment_method ที่ตำแหน่ง L; Payments เพิ่ม payment_method ที่ตำแหน่ง H

### ถ้าสร้างร้านใหม่ 50 ขวดไปแล้ว
1. สำรอง Google Sheets ก่อน (File > Make a copy)
2. แทนที่ Code.gs, Index, Styles, Client ด้วยไฟล์ชุดนี้
3. Save แล้วเลือกฟังก์ชัน `enableCashPayments` กด Run หนึ่งครั้ง
4. ห้ามรัน `setupNewStore` อีกครั้ง
5. Deploy > Manage deployments > Edit > New version > Deploy
6. ทดลองเลือกเงินสดหนึ่งขวด ตรวจว่าเป็น CASH_PENDING และ Admin สามารถกดยืนยันเมื่อรับเงินสดจริง

### ถ้ายังไม่ได้สร้างร้านใหม่
คัดลอกไฟล์ชุดนี้และรัน setupNewStore ครั้งเดียวตามคู่มือเดิม โดยไม่ต้องรัน enableCashPayments

**คำเตือน:** ไม่มีฮาร์ดแวร์ตรวจจับการหยิบจริง ผู้ซื้อพิมพ์ชื่อเอง จึงไม่สามารถพิสูจน์ตัวตนได้ การเลือกเงินสดไม่ใช่หลักฐานว่าเจ้าของร้านได้รับเงินแล้ว
